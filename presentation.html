Flux de Traitement d'une Requête

1️⃣ Requête HTTP

L'utilisateur soumet le formulaire React. Axios envoie une requête POST /users avec des données JSON.

2️⃣ Validation FastAPI

La passerelle reçoit la requête, valide automatiquement les données avec Pydantic.

3️⃣ Conversion JSON → Protobuf

FastAPI crée un message Protocol Buffers à partir des données JSON.

4️⃣ Appel gRPC

Le client gRPC envoie la requête binaire au serveur via HTTP/2.

5️⃣ Traitement Backend

Le serveur gRPC traite la logique métier et crée l'utilisateur.

6️⃣ Réponse Protobuf → JSON

La réponse remonte: gRPC → FastAPI (conversion JSON) → React (affichage).
